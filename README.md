# Мини ТЗ

Целью является написать модуль для небольшого интернет-магазина. Есть список заказов, и их нужно обработать.

## Шаг 1. Работа в Git
1. Открой свой учебный репозиторий в терминале.
2. Создай новую ветку с именем `feature-expenses-fix` и перейди в неё.
3. Создай файл `expenses_practice.py`.

## Шаг 2. Исходные данные
```purchases = [```
    ```{"item": "Книга по Python", "category": "Образование", "price": 1500},```
    ```{"item": "Кофе", "category": "Еда", "price": 250},```
    ```{"item": "Подписка на музыку", "category": "Развлечения", "price": 0}, # Бесплатный период```
    ```{"item": "Курс по Git", "category": "Образование", "price": 3000},```
```]```

## Шаг 3. Написание кода 
1. Фильтрация через Comprehension: С помощью list comprehension (генератора списков) отфильтруй список `purchases` так, чтобы в новый список попали только те покупки, у которых цена (`price`) строго больше 0. Назови новый список `paid_purchases`.
2. Создание функции с **kwargs: Напиши обычную функцию `def show_purchase_details(item, category, price):`. Внутри неё через f-строку выведи красивый текст: `Товар: [название], Категория: [категория], Стоимость: [цена] руб`.
3. Вызов через распаковку: Возьми самый первый элемент из твоего отфильтрованного списка `paid_purchases` и передай его в функцию `show_purchase_details` с помощью распаковки словаря (`**`).

## Шаг 4. Предсказание и Проверка
1. Прямо в комментариях к коду напиши предсказание: какой именно товар выведется на экран на шаге 3.3?
2. Запусти код в терминале и проверь результат.

## Шаг 5. Финал в Git
1. Добавь файл в индекс (`git add`).
2. Сделай коммит (`git commit`) с понятным сообщением (например, `"feat: filter expenses and add print function"`).
3. Отправь ветку на GitHub (`git push`).
